# John Rey Marquillero — Portfolio

Personal site for a UX Engineer, UX Writer and UX Researcher.

Built with Next.js, Tailwind CSS, GSAP (ScrollTrigger + SplitText), Motion, Lenis smooth scroll and React Three Fiber for the floating 3D shapes in the hero.

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Editing content

All copy (bio, roles, projects, toolbox) lives in `src/lib/content.ts`. Images are in `public/img`.

## Deploy

Pushed to GitHub and imported into Vercel. Every push to `main` redeploys.
